##Sentinel
A lightweight Roblox utility package featuring logging, debugging, table and string helpers, math utilities, callbacks, thread management, number formatting, and more. A collection of useful tools in one module.

##Features
Logging — Printing, warnings, errors, and assertions.

Debugging — Tracebacks, profiling, and memory tags.

Tables — Deep cloning, comparison, freezing, merging, and more.

Strings — Capitalization, trimming, and splitting.

Math — Clamping, rounding, interpolation, and sign.

Callbacks — Protected calls and retry functionality.

Threads — Task spawning, delaying, deferring, and cancellation.

Utilities — Number formatting with abbreviations and commas.

##Installation
Get Sentinel from the Roblox Creator Store and insert it into your game (https://create.roblox.com/store/asset/88532361626062/Sentinel?keyword=Sentinel&pageNumber=0&pagePosition=26) or download it in this repository.
